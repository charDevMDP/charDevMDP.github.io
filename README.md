# charDev

Sitio de desarrollador: https://chardevmdp.github.io/

- `index.html`: portada con la lista de apps (SuguruNeon, GeLi), sus enlaces a Google Play y a su política de privacidad. Al sumar una app, se agrega una tarjeta acá.
- `app-ads.txt`: lo lee AdMob para verificar que las unidades de anuncios son nuestras. La línea lleva el ID de editor, que es de la cuenta y no de cada app: **sirve para todas las apps**. Si alguna usa otra cuenta de AdMob, se agrega otra línea.

La política de privacidad de cada app vive en su propio repo (`geli-legal`, `suguruneon-legal`), publicada bajo este mismo dominio.
